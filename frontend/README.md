# 프론트엔드 · 제주 상권 브리핑

제주데이터허브 608번 자료를 지역·관광객 구분·기간별로 나눠 토요일과 일요일의 카드 이용을 비교하는 화면입니다. HTML, CSS, 브라우저 자바스크립트로 구성했습니다.

## 실행

1. [프로젝트 README](../README.md)의 방법으로 백엔드를 실행합니다.
2. 브라우저에서 `http://127.0.0.1:8000/`을 엽니다.

백엔드가 `/`에서 화면을, `/assets/`에서 CSS와 자바스크립트를 제공합니다. 같은 주소의 `/api/` 경로를 호출하므로 브라우저에서 HTML 파일을 직접 여는 대신 백엔드 주소로 접속합니다.

## 화면 사용법

1. 화면 위의 **데모 데이터** 또는 **실제 데이터** 표시를 확인합니다. 데모 화면의 수치는 동작 확인용입니다.
2. **지역과 관광객별 주말 비교**에서 지역·관광객 구분·기간·지표를 골라 같은 조건으로 여러 그룹을 비교합니다. 월별 결과를 펼치면 각 달에 어느 요일이 더 높았는지 확인할 수 있습니다.
3. 개별 비교에서는 지역과 관광객 구분을 선택하면 해당 조합에 맞게 시작 월과 종료 월이 갱신됩니다. 기간과 지표를 선택한 뒤 **토·일 비교하기**를 누릅니다.
4. 결과에서 비교 기준, 요일별 합계, 포함 일수, 일평균, 포함·제외 월, 출처를 확인합니다. 원자료의 관측 기간과 수집일이 제공되면 별도로 표시합니다. 일평균과 금액 단위 표시는 백엔드 데이터 설정에 따릅니다.
5. **AI에게 물어보기**에서 `두 구도심 모두 토요일 소비가 더 많았어?`, `그 차이가 매달 비슷했어?`, `그럼 서귀포만 보면?`처럼 이어서 질문합니다. 화면에서 선택한 분석과 적용한 조건을 확인할 수 있습니다. `올해도 그래?`처럼 관측 범위를 확인하는 질문은 요청 기간과 실제 관측 기간을 보여줍니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 비교 조건, 질문 입력, 결과 영역의 구조와 접근성 라벨 |
| `assets/styles.css` | 반응형 레이아웃, 상태 표시, 토·일 비교 차트 |
| `assets/app.js` | API 요청, 폼 상태, 차트·표·메시지 표시 |

## 백엔드 연동

| 경로 | 용도 |
|---|---|
| `GET /api/options` | 데이터 모드, 지역·관광객 구분별 비교 가능 월과 공통 비교월, 지표, AI 연결 설정 확인 |
| `POST /api/compare` | 선택한 지역·관광객 구분(`visitor_type`)·기간·지표의 요일별 비교 결과 조회 |
| `POST /api/compare-groups` | 선택한 지역·관광객 구분의 공통 기간으로 그룹별 요일 결과와 월별 추이 조회 |
| `POST /api/agent` | 질문과 직전 분석 조건을 보내 분석 결과, 관측 범위 또는 확인 질문 받기 |

숫자는 백엔드 집계 결과로 표시합니다. NVIDIA API 키와 데이터 접근 설정은 [백엔드 README](../backend/README.md)를 참고합니다.
