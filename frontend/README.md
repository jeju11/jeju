# 프론트엔드 · 제주 상권 브리핑

제주데이터허브 608번 자료를 지역·관광객 구분·기간별로 나눠 토요일과 일요일의 카드 이용을 비교하는 화면입니다. HTML, CSS, 브라우저 자바스크립트로 구성했습니다.

## 실행

1. [프로젝트 README](../README.md)의 방법으로 백엔드를 실행합니다.
2. 브라우저에서 `http://127.0.0.1:8000/`을 엽니다.

백엔드가 `/`에서 화면을, `/assets/`에서 CSS와 자바스크립트를 제공합니다. 같은 주소의 `/api/` 경로를 호출하므로 브라우저에서 HTML 파일을 직접 여는 대신 백엔드 주소로 접속합니다.

## 화면 사용법

1. 화면 위의 **데모 데이터** 또는 **실제 데이터** 표시를 확인합니다. 데모 화면의 수치는 동작 확인용입니다.
2. 지역과 관광객 구분을 선택하면 해당 조합에 맞게 시작 월과 종료 월이 갱신됩니다. 기간과 카드 이용 건수 또는 금액을 선택하고 **토·일 비교하기**를 누릅니다.
3. 결과에서 비교 기준, 요일별 합계, 포함 일수, 일평균, 포함·제외 월, 출처를 확인합니다. 원자료의 관측 기간과 수집일이 제공되면 별도로 표시합니다. 일평균과 금액 단위 표시는 백엔드 데이터 설정에 따릅니다.
4. NVIDIA NIM 연결이 설정되어 있다면 **AI에게 물어보기**에서 `서귀포시 구도심의 내국인 관광객 이용 건수를 비교해줘`처럼 질문할 수 있습니다. 질문에서 빠진 조건의 문맥으로 현재 선택을 전달합니다. 에이전트가 추가 설명을 요청하면 질문을 구체화해 다시 입력합니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 비교 조건, 질문 입력, 결과 영역의 구조와 접근성 라벨 |
| `assets/styles.css` | 반응형 레이아웃, 상태 표시, 토·일 비교 차트 |
| `assets/app.js` | API 요청, 폼 상태, 차트·표·메시지 표시 |

## 백엔드 연동

| 경로 | 용도 |
|---|---|
| `GET /api/options` | 데이터 모드, 지역·관광객 구분별 비교 가능 월, 지표, AI 연결 설정 확인 |
| `POST /api/compare` | 선택한 지역·관광객 구분(`visitor_type`)·기간·지표의 요일별 비교 결과 조회 |
| `POST /api/agent` | 질문과 현재 선택을 보내 새 비교 결과 또는 확인 질문 받기 |

숫자는 백엔드 집계 결과로 표시합니다. NVIDIA API 키와 데이터 접근 설정은 [백엔드 README](../backend/README.md)를 참고합니다.
