# Jeju Data Agent

제주 구도심의 주말 카드 이용을 비교하는 AI 에이전트입니다. 사용자가 자연어로 질문하면 조회 조건과 분석 도구를 선택하고, 제주데이터허브 608번 자료를 집계해 수치·차트·분석 조건·출처를 제공합니다.

제주 AI·빅데이터 활용 AI Agent 개발 챌린지를 위해 구현했습니다. 도민과 상권 관계자가 두 구도심의 과거 소비 패턴을 살펴보고, 센터 상담이나 공공데이터 교육에서 근거를 확인할 수 있도록 구성했습니다.

**[운영 시연 열기](https://jeju-data-agent.vercel.app/) · [사용자 화면 안내](frontend/README.md) · [백엔드 및 데이터 명세](backend/README.md)**

## 심사 시 확인할 흐름

1. 운영 시연에서 첫 번째 예시를 눌러 질문창에 문장을 채우고 **질문하기**를 누릅니다.
2. 2017년 11월의 두 구도심 카드 이용 건수와 차트, 관광객 구분, 출처를 확인합니다.
3. **다시 비교하기**에서 월별 추이를 요청하거나 **데이터 둘러보기**에서 기간·지역·관광객 유형을 직접 선택합니다.
4. 로컬 재현은 아래 설치 절차를 사용합니다. 제출 ZIP에는 실제 수집본과 실행 매뉴얼이 함께 제공됩니다.

실제 608번 수집본에서 2017년 11월 두 관광객 유형의 토·일 이용 건수를 합산하면 다음과 같습니다.

| 지표 | 제주시 구도심 | 서귀포시 구도심 |
| --- | ---: | ---: |
| 주말 카드 이용 건수 | 27,347건 | 22,103건 |

두 지역의 차이는 **5,244건**입니다. 위 값은 실제 수집본의 검증 기준이며, 저장소의 합성 데모 데이터에서는 다른 값이 나옵니다.

## Agent가 수행하는 일

```text
질문과 직전 분석 조건
  → NVIDIA NIM이 허용된 도구와 조회 조건 선택
  → FastAPI가 인자 검증
  → DuckDB가 공통 관측월의 카드 이용 집계
  → 비교 수치·월별 추이·조건·출처 표시
```

| 기능 | 구현 내용 |
| --- | --- |
| 자연어 분석 | 지역·관광객 유형·기간·지표 해석, 부족한 조건에 대한 보충 질문 |
| 비교 도구 | 요일 비교, 집단 비교, 월별 추이, 관측 기간 확인 |
| 결과 확인 | 지역별 합계, 막대·선 차트, 관광객 유형별 표, 기간과 출처 |
| 직접 선택 | NVIDIA 키 없이 CSV 기반 비교 실행 |
| 후속 사용 | 직전 조건을 이어 질문, 회의용 요약 복사, 브라우저에 질문 저장 |

기본 모델은 `nvidia/nemotron-3.5-lightning-30b-a3b`입니다. 모델은 도구 한 개와 인자를 선택하고, 집계는 서버 코드가 수행합니다. 프롬프트와 도구 정의는 [backend/agent.py](backend/agent.py)에 있습니다.

## Windows에서 설치하고 실행

Windows x64와 Python 3.12를 기준으로 합니다. 저장소를 내려받거나 제출 ZIP을 풀고 루트 폴더에서 실행합니다.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r .\backend\requirements.txt
if (-not (Test-Path .\backend\.env)) {
    Copy-Item .\backend\.env.example .\backend\.env
}
.\backend\start.cmd
```

[로컬 화면](http://127.0.0.1:8000/)과 [API 문서](http://127.0.0.1:8000/docs)를 엽니다. 실행 창에서 `Ctrl+C`로 종료합니다.

| 실행 경로 | 필요한 설정 |
| --- | --- |
| GitHub 소스에서 빠르게 확인 | 기본 제공 `demo_608.csv` 사용. 화면에 합성 데모 표시 |
| 심사용 ZIP의 실제 수집본 사용 | CSV와 같은 이름의 메타데이터 JSON을 `backend/data/`에 두고 `JEJU_DATA_CSV=data/jeju_608.csv` 설정 |
| 새 데이터 수집 | 제주데이터허브 프로젝트 키 설정 후 수집 명령 실행. [수집 방법](backend/README.md#실제-608번-자료-연결) |
| 자유 질문 사용 | `backend/.env`에 `NVIDIA_API_KEY` 입력 후 서버 재시작 |

시작 후 `/api/options`의 `mode`가 `real`이면 실제 수집본이 연결됐고, `ai_available`이 `true`이면 AI 키가 설정된 상태입니다. 자유 질문의 실제 성공 여부는 대표 질문을 제출해 확인합니다. 예시와 직접 선택은 AI 키 없이 실행할 수 있습니다.

## 데이터와 해석 범위

- **출처**는 제주특별자치도 제공 제주데이터허브 608번 「관광지 및 상업지구 요일별 카드 데이터」입니다. [제주데이터허브](https://jejudatahub.net/data/view/data/608) · [공공데이터포털 동명 API](https://www.data.go.kr/data/15094893/openapi.do)
- 실제 수집본은 **2016년 9월~2017년 11월**, 제주시·서귀포시 구도심, 내국인·중국인 관광객을 포함하는 **420행**입니다. 비교에는 각 집단에 토·일 관측이 함께 있는 공통 월을 사용합니다.
- 이용 건수는 카드 이용 횟수입니다. 수집본의 금액 단위가 확인되지 않아 금액은 **원자료 단위**로 표시합니다. 업종 구분과 현재 시점의 관측은 이 수집본에 포함되지 않습니다.
- 이용조건, 수집·전처리와 검증 기준은 [데이터 명세](backend/README.md#데이터-스키마와-집계-기준)에 설명합니다. 실제 수집 파일과 키는 Git 제외 대상입니다.

## 실행 환경과 외부 의존성

로컬 PC에서 브라우저·FastAPI·DuckDB를 실행합니다. NVIDIA 추론은 외부 API에서 수행하므로 로컬 GPU에 모델을 탑재하는 절차는 없습니다. 패키지 설치 시 인터넷이 필요하고, 자유 질문에는 NVIDIA HTTPS 연결과 참가자가 준비한 평가용 키가 필요합니다. 새 수집에는 제주데이터허브 API와 프로젝트 키가 필요합니다.

센터의 제시 사양은 Intel Core i7-8700, GTX 1060, RAM 32GB, VRAM 3072MB입니다. Windows 새 가상 환경에서 ZIP 실행을 확인했으며, 실제 센터 PC의 네트워크와 평가용 키는 평가 환경에서 확인해야 합니다.

## 검증

```powershell
Push-Location .\backend
..\.venv\Scripts\python.exe -m unittest discover -s tests -v
Pop-Location
```

백엔드 테스트 **37개**로 전처리·집계·도구 호출·관측 범위 안내를 검증합니다. 별도로 ZIP에서 새 Windows 가상 환경을 만든 뒤 실제 데이터 비교, NVIDIA 기본 모델 자유 질문, 3개월 추이와 범위 밖 직접 비교 처리를 확인했습니다. 화면은 390px~1920px에서 확인했습니다.

연결 오류가 나면 키·할당량·HTTPS 접속을 확인하고 직접 선택으로 분석할 수 있습니다. CSV 오류는 수집본과 메타데이터를 함께 복원하고 서버를 다시 시작합니다.

## 개발 도구와 외부 코드

Python 3.12, DuckDB, FastAPI, HTTPX, Pydantic, python-dotenv, Uvicorn을 사용합니다. 버전은 [의존성 목록](backend/requirements.txt)에 있습니다. Codex와 Vercel v0를 코드·디자인 초안, 수정과 검증에 사용했습니다. 이미지·화면 에셋 출처는 [프런트엔드 명세](frontend/README.md#에셋과-제작-도구)에 기록했습니다.

## Vercel 운영 시연 배포

루트 폴더를 Vercel 프로젝트에 연결하고 운영 환경 변수에 `JEJU_DATA_CSV=data/jeju_608.csv`와 `NVIDIA_API_KEY`를 설정합니다. 실제 CSV와 JSON이 로컬에 있는 상태에서 루트에서 `npx vercel@50 deploy --prod`를 실행합니다. 화면과 API는 하나의 주소에서 제공됩니다. GitHub에서 받은 소스만으로 배포할 때는 먼저 실제 자료 파일을 준비해야 합니다.
