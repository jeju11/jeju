HTTP 확인에는 시작/입력 화면, 질문과 직접 선택의 수치 일치, 월별 후속 질문, 지역만 바꾸기, 네 조합 15개월, 기간 밖 자료 없음, 부분 기간 교집합, 잘못된 요청/출처, 요청 크기, 관리자·자료 가져오기·예약 갱신 접근 차단이 포함됩니다.
