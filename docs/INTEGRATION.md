## 범위와 한계

- 통합 실행 경로는 Next.js 한 개입니다. Python 원본은 legacy에 보관되어 자동 배포되거나 실행되지 않습니다.
- dev1의 금액·달력 일수·일평균 처리는 원본에 보존합니다. 현재 내장 데이터는 useCount만 있으므로 통합 화면에서는 금액/일평균을 활성화하지 않습니다.
- 자연어 기본 해석은 명시적인 한국어 지역·유형·기간 질문을 대상으로 합니다. 지원하지 않는 표현은 확인 안내를 하고, 예측·시간대·개별 매장·금액 요청을 임의로 다른 지표로 바꾸지 않습니다.
- NVIDIA는 서버에서 허용된 네 도구만 선택할 수 있습니다. 명시한 지역·관광객·기간과 충돌하거나 응답이 잘못되면 기본 해석 결과를 사용하고 알립니다. 규칙에 없는 표현과 암시적인 월별 질문은 모델이 도구를 선택할 수 있습니다. 규칙 해석도 불가능하고 모델도 실패하면 임의 결과 대신 조건 확인을 요청합니다. 이를 자유로운 SQL 생성으로 설명해서는 안 됩니다.
- 외부 모델의 응답 시간/정확도, 실제 DB 마이그레이션과 자동 갱신은 참가자의 키와 별도 환경이 필요합니다. 모의 응답 테스트를 실제 API 호출 성공으로 표현하지 않습니다.
- 사용자별 이력을 활성화하려면 0003 마이그레이션도 적용합니다. 기존 버전의 이력은 저장된 단일 조건으로 재조회하며 원래 질문을 다시 해석하지 않습니다.
- 여러 집단에서 어느 한쪽 요일이 누락되면 그 월은 모든 집단의 합계에서 제외합니다. 전체가 0건일 때는 요일 비중을 계산하지 않습니다.
- 기본 화면에는 계정·결제 메뉴가 없습니다. 계정·관리자 기능은 설정된 환경의 별도 경로로만 유지합니다.

## 재현 가능한 확인

`pnpm test`, `pnpm typecheck`, `pnpm build`를 실행합니다. 로컬 빌드 서버를 켠 뒤 `pnpm test:smoke`로 실제 화면과 API를 확인합니다. 테스트는 기본 파일 모드이며 실제 사용자 DB나 유료 API를 호출하지 않습니다.
