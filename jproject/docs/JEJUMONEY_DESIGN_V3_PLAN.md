# 제주머니(JejuMoney) 디자인 v3.0 톤앤매너 전면 개편 계획서

> **문서 버전**: v3.0  
> **작성 일자**: 2026-11-18  
> **기준 문서**: `desgin.md` (제주머니 - 제주 구도심 주말 카드소비 비교 포털)  
> **핵심 타깃**: 제주도 도민, 제주시·서귀포시 구도심 소상공인, 상인회 실무자  
> **핵심 목적**: 복잡한 공공 빅데이터(제주데이터허브 제608호)를 자연어 질문 및 손쉬운 3열 조건 선택을 통해 직관적으로 비교·해석하는 체감형 공공 웹 서비스 구축

---

## 1. 개편 배경 및 방향성 (Key Paradigm Shift)

| 구분 | 기존 (v2.0 공공 행정 포털) | 신규 개편 (v3.0 제주머니 포털) |
| :--- | :--- | :--- |
| **서비스 명칭** | 제주 주말소비 분석 포털 (JTP 테크노파크) | **제주머니 (JejuMoney)** - 구도심 주말 카드소비 비교 |
| **톤앤매너** | 정형화된 공공 행정 대시보드, 다층 카드 | **Jeju Civic & Calm (친근하고 신뢰감 있는 제주 감성)** |
| **디자인 모티프** | 네이비 관공서 그리드, 다중 탭 | **한라산 능선 & 제주 바다 수평선 SVG 곡선, 감귤 포인트** |
| **사용자 접근성** | 로그인/회원가입/권한 제어 중심 | **로그인 요소 전면 배제, 첫 방문 즉시 100% 탐색 가능** |
| **데이터 전달 방식**| 지표 나열 및 복합 차트 분석 | **원라인 자연어 결론 ("토요일에 카드 결제가 288건 더 많았어요")** |
| **시각화 표준** | 다양한 복합 차트 및 지도 | **착시 없는 0-기준 동일 눈금 가로 막대 그래프** |
| **터치 타깃 규격**| 표준 데스크톱 컴팩트 버튼 (36~40px) | **소상공인·고령층 친화 최소 48px 이상의 대형 세그먼트 버튼** |

## 2. 디자인 토큰 및 디자인 시스템 규격

### 2.1 컬러 팔레트 (Color Tokens)
```css
:root {
  /* 주조색 & 브랜드 */
  --primary-blue: #005BAC;       /* 메인 블루, 공공 신뢰 블루, 주요 액션 버튼 */
  --primary-dark: #0F172A;       /* 헤드라인, 핵심 텍스트 (slate-900) */
  --accent-tangerine: #EA580C;   /* 제주 감귤 포인트 오렌지 (칩 보더, 하이라이트) */

  /* 데이터 시각화 전용 컬러 */
  --data-saturday: #0D9488;      /* 토요일 전용 데이터 컬러 (청록 / Teal 600) */
  --data-sunday: #2563EB;        /* 일요일 전용 데이터 컬러 (블루 / Blue 600) */

  /* 배경 & 서피스 */
  --bg-page: #F8F9FA;            /* 전체 페이지 기본 배경 (오프화이트) */
  --bg-hero-top: #F0F7FF;        /* 히어로 배경 상단 그라데이션 시작 */
  --bg-hero-bottom: #E6F4FE;     /* 히어로 배경 하단 그라데이션 종료 */
  --surface-white: #FFFFFF;      /* 메인 카드, 입력창, 선택 버튼 기본 배경 */
  --surface-subtle: #F1F5F9;     /* 미선택 버튼, 비활성 칩, 표 헤더 (slate-100) */
  --border-default: #E2E8F0;     /* 카드 테두리, 구분선 (slate-200) */
}
```

### 2.2 타이포그래피 (Typography System)
- **기본 글꼴**: `Pretendard`, `Noto Sans KR`, `-apple-system`, `sans-serif`
- **숫자 렌더링**: 수치 비교, 통계표, 메트릭 카드 전역에 `font-variant-numeric: tabular-nums` (`tabular-nums`) 필수 적용.
- **주요 폰트 스케일**:
  - `Hero Title`: 28px ~ 32px / Bold (700) / `#0F172A`
  - `Headline Result`: 24px ~ 28px / Bold (700) / `#0F172A`
  - `Metric Large`: 36px ~ 40px / Bold (700) / 토요일 `#0D9488`, 일요일 `#2563EB`
  - `Section Title`: 18px ~ 20px / Bold (700) / `#0F172A`
  - `Body / Label`: 15px ~ 16px / Medium (500) / `#334155`
  - `Caption / Meta`: 12px ~ 13px / Regular (400) / `#64748B`

## 3. 화면별 구현 및 개편 상세 계획

### 3.1 메인 포털 화면 (통합 '제주머니' 웹 데스크톱 포털: `app/page.tsx`)
최대 너비 `max-w-[1080px]` 중앙 정렬 컨테이너 안에서 사용자가 첫 진입부터 결론 확인까지 물 흐르듯 탐색하는 단일 통합 경험 제공:

1. **상단 내비게이션 & 헤더 (`Top Navigation`)**
   - 높이: `h-16` (64px) Sticky 고정 (`bg-white/95 backdrop-blur-sm border-b border-slate-200`).
   - 좌측: 한라산 능선 & 제주 바다 물결 SVG 심벌 (28x28px) + "제주머니" 로고 (18px, Bold, `#0F172A`) + "구도심 소비 분석" 캡슐 뱃지.
   - 우측: "데이터 출처 : 제주데이터허브 제608호" + 외부 링크 아이콘 (`open_in_new`).
   - **로그인/회원가입 UI 전면 배제** (도민 누구나 무설치·무가입 즉각 사용).

2. **히어로 섹션 & 자연어 검색창**
   - 은은한 하늘색 배너 (`#F0F7FF` ~ `#E6F4FE`) + 완만한 한라산 능선과 바다 수평선 실루엣 곡선 SVG 배경.
   - 메인 카피: *"제주의 주말 소비, 궁금한 건 편하게 물어보세요"*
   - 검색창: 높이 `h-16` (64px), `rounded-2xl`, `border-2 border-[#005BAC]`, 좌측 돋보기 아이콘, 우측 48px [결과 보기] CTA 버튼.
   - 추천 질문 칩 (Prompt Chips): 감귤색 톤(`bg-amber-50 border-amber-200 text-amber-900`) 적용.
     - 예: `'17년 11월 비교'`, `'그럼 서귀포는?'`, `'그 차이가 매달 비슷했어?'`
     - 클릭 시 입력창 자동 입력 및 즉각 시뮬레이션 질의 파싱 연동.

3. **‘직접 골라도 돼요’ 통합 선택기 패널 (3열 그리드)**
   - `bg-white border border-slate-200 rounded-2xl shadow-sm p-6 sm:p-7`.
   - **열 1 (지역 구분)**: 제주시 구도심 / 서귀포시 구도심 (48px 세그먼트 버튼, 선택 시 `#005BAC` + 체크 아이콘).
   - **열 2 (소비 주체)**: 내국인 관광객 / 중국인 관광객 (48px 세그먼트 버튼).
   - **열 3 (기간 선택)**: 시작월(YYYY-MM) ~ 종료월(YYYY-MM) 드롭다운 셀렉트.
   - 하단 안내 문구: *"자료가 있는 기간은 2016년 9월부터 2017년 11월까지예요"*.
   - **[고른 조건으로 비교하기]** 48px 대형 실행 버튼 (`#005BAC`).

4. **비교 결과 섹션 (`Comparison Result`)**
   - **조건 뱃지**: `[적용 조건] 제주시 구도심 · 내국인 관광객 · 2017년 11월`.
   - **원라인 핵심 결론**: `토요일에 카드 결제가 288건 더 많았어요` (26~30px Bold).
   - **2열 나란한 메트릭 카드**:
     - 토요일 카드: 연한 청록 배경(`teal-50`), 청록 테두리, 수치 `13,502건` (`#0D9488`), 상단 `우세 (+288)` 뱃지.
     - 일요일 카드: 연한 블루 배경(`blue-50`), 블루 테두리, 수치 `13,214건` (`#2563EB`), 상단 `안정 소비` 뱃지.
   - **0 기준 동일 눈금 가로 막대 그래프 (Zero-baseline Bar Chart)**:
     - 0건부터 Max까지 동일 눈금 스케일 적용 (착시 없는 정직한 시각화).
     - 토요일 막대(`#0D9488`)와 일요일 막대(`#2563EB`) 상하 나란히 배치 및 우측 천 단위 건수 표기.

5. **‘달마다 어떻게 달랐나요?’ 월별 추이 표**
   - 4열 테이블: `월`, `토요일`, `일요일`, `차이`.
   - 전 수치 `tabular-nums` 및 우측 정렬.
   - 현재 조회 중인 월(예: 2017년 11월) 라이트 청록 배경 및 `선택` 뱃지 하이라이트.
   - 차이 열: 단순 +/- 기호 대신 직관적인 자연어 뱃지 (`토요일 288건 많음`, `일요일 340건 많음`).

6. **‘자료와 계산 방법 보기’ 아코디언**
   - 기본 닫힘 상태(접힘)로 시각적 피로도 최소화.
   - 제주데이터허브 제608호 공공데이터 출처 안내.
   - 1:1 토·일 페어링 원칙 설명 ("토요일·일요일 자료가 모두 있는 달만 골라 합산").
   - 공식 관측 기간(2016.09 ~ 2017.11 총 15개월) 및 왜곡 방지 제외 기준 명시.
